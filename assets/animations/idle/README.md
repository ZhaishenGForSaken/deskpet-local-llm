# 动画素材目录

请将 .webm 格式的动画文件放入对应目录：

## 闲置动画 (idle/)
桌宠空闲时随机播放的动画，建议 3-5 秒循环视频。

## 点击反应动画 (click/)
点击桌宠时播放的反应动画，建议 1-3 秒单次播放。

## 格式要求
- 格式: WebM (VP8/VP9 编码)
- 建议启用透明通道 (Alpha)
- 分辨率: 建议 512x512 以内
- 大小: 每个文件建议 < 5MB

## 获取动画素材
- 自行制作：使用 After Effects、Blender 等工具
- 在线资源：搜索 "animated pet webm" 或 "live2d webm"
- 社区分享：加入我们的社区获取更多素材
